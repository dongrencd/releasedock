# Windows UI

## 设计目标

Windows 首屏是管理台，不是欢迎页。核心任务是让用户快速判断哪些 GitHub Release 软件需要更新，并在更新前查看原始 release note。

## 布局

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ GitHub Release Manager       搜索软件 / 仓库 URL              [+ 添加] [检查] │
├───────────┬───────────────────────────────────────────────┬────────────────┤
│ 更新收件箱 │  待处理更新                                    │  详情检查器     │
│ 软件库     │  应用        当前     最新     判断        操作 │  Release note   │
│ 发现       │  LosslessCut 3.64    3.65    建议更新    更新 │  资产文件       │
│ 活动       │  micro       2.0.14  2.0.14  最新        打开 │  安装路径       │
│ 设置       │                                               │  Release 链接   │
├───────────┴───────────────────────────────────────────────┴────────────────┤
│ 下载 owner/repo v1.2.3    █████████░░  78%      取消                         │
└────────────────────────────────────────────────────────────────────────────┘
```

## 页面

- 更新收件箱：默认首页，只显示需要处理的更新、失败和需要选择资产的软件。
- 软件库：所有已管理软件。
- 发现：输入 GitHub URL 或 `owner/repo`，生成安装计划。
- 活动：下载、解压、安装、卸载、回滚日志。
- 设置：GitHub token、安装目录、代理、更新策略。

## 视觉

- 背景：`#F5F7FA`
- 面板：`#FFFFFF`
- 主色：`#0F766E`
- 待确认色：`#B45309`
- 失败色：`#B91C1C`
- 字体：`Segoe UI`
- 版本号、路径、asset 名：`Cascadia Mono`

布局偏桌面管理工具，使用表格和详情检查器，避免营销卡片式首页。
